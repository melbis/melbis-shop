# Report Editor

The "Report Editor" section (the "Development" tab) is used for creating reports and
configuring access to them.

On the left is the **"Report Catalog"** (tree). Functions: adding sections and reports,
**"Launch Report Designer"** (FastReport visual constructor), **"Load
Report from File"** and **"Save Report to File"**. On the right are **"Permissions for User
Groups"** and **"Permissions for Users"** (access to the report).
Users with management rights get access to all reports automatically.

Finished reports are launched from the "Orders", "Prices" and "Customers" sections (see
"[Reports](reports.md)").
