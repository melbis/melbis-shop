# Reports

Reports generate and print documents using the FastReport engine — accompanying
documents for orders and various summaries.

## How to run a report

In the "Orders", "Prices", and "Customers" sections, there is a **"Reports"** panel and a
**"Show Report"** button: select the desired report from the list and click **"Show
Report"**. Some reports request additional parameters before generating
(for example, selecting an executor and supplier for a purchase summary). The finished report
opens in a preview window, from which it can be printed.

For example, for an order you can get an order form, a sales receipt with a warranty card,
and a bill of lading, and for items with the "For Purchase" status — a purchase summary
grouped by suppliers.

## Report configuration

The reports themselves and access rights to them are created and configured in the
"Development" → "Report Editor" section (see "[Report Editor](report-editor.md)").
