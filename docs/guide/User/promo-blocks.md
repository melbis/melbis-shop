# Promo Blocks

The "Promo Blocks" section is a universal tool for marketing, navigation,
text, and banner blocks of the store.

On the left is a tree-structured catalog **"Blocks"**, on the right are three sections of the selected block:
**"Text Values"**, **"Product Values"**, and **"Block Binding"**.

The section is edited **in lock mode** — see "[Three Data Working Modes](basics.md)".

## Blocks

Controls: **"Add Section"** / **"Add Subsection"**, **"Edit"**,
**"Delete"**, move, and **"Set/Reset Block Flag"** (folder or
element). Block fields: **Key**, **Name**, and **Type** (configurable, see
"[Settings Registry](registry.md)").

## Text Values

Block records contain: **Date and Time**, **Name**, **Text Content**,
**Type**, and **Parameters**, as well as a large **Text** field (HTML with associated
files). Values can be added, edited, deleted, and moved; they can be
dragged between blocks.

## Product Values

Products can be bound to a block with the fields **Type**, **Parameters**, and **Notes** (by
default — the product name).

## Block Binding

Defines where the block is displayed. Fields: **"Bind to Object"** (basic options are "To
Section" and "To Product", the list is expandable), **"Binding Type"**, **"Object ID"** (a
button allows selecting a section or product), **Parameters**, and **Notes**.
A block can have multiple bindings.
