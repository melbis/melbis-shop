# Multilingualism

The "Multilingualism" section (the "Structure" tab) is used for translating store elements into other languages, both manually and automatically. It consists of two windows: **"Languages and Categories"** and **"Translations"**.

## Languages and Categories

This is where the store's languages and categories of translatable content are defined.

On the left is **"Categories"** (a tree-structured catalog of translatable content): **"Add section"** / **"Add subsection"**, editing, deletion, moving, and **"Set/reset block flag"**. On the right is **"Languages"**: adding, editing, deleting, and moving. The language and category fields are: **Key**, **Name**, **Description**, **Type**, **Parameters**, and the **"Original"** flag.

## Translations

A window consisting of three parts: **"Categories"** (on the left), **"Original"** (in the center), and **"Translation"** (on the right), plus a built-in web module.

* **Original** — the source texts of the selected category: **"Get translations for the current category"**, adding, editing, deletion, **"Save order"**. Each record displays the flags **"Active"**, **"Updated"**, **"HTML"**, and **"No translation"**, as well as **Context**, a link to the element (ID and code), and the original text itself.
* **Translation** — translations of the original by language: **"Add translation"**, editing, deletion, and **"Instant translation"** (automatic translation of a string). Each translation has a **Language**, the translation text, and the flags **"Approved"** and **"Error"**.

This way, any store element can be translated manually or automatically, with translations managed under full control — including approval and error flagging.
