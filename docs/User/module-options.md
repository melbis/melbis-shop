# Modules and Options

The "Modules and Options" section (the "Development" tab) is for configuring the store's web modules. Three tabs.

* **External modules** — **"Module catalog"** and **"Module parameters"**: **Module URL**, **Key (module name)**, the **"User identification required"** checkbox, and group and user permissions. External modules work both in the application and in the browser.
* **Built-in modules** — by **"Location"** (products, orders, customers, scheduler, translator, invisible): a list of modules with the same parameters; they are embedded in the panels of the corresponding sections.
* **Module options** — a catalog of options and their values (Key, Name, Type, Parameters), which modules read and write, with **Read / Write / Delete** access rights by groups and users.

Working with ready-made modules is described in "[Web Modules](web-modules.md)".
