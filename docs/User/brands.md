# Brands

The "Brands" section is a reference directory of product brands available in the store.

The directory is straightforward: **"Add brand"**, **"Edit brand"**, **"Delete
brands"**, navigation through the list, and **"Save order"** (for example, sort
by the "Brand name" column and save the new numbering). The section
is edited **in lock mode** — changes are applied using the "Save"
/ "Save and exit" buttons (see "[Three data management modes](basics.md)").

## Brand fields

* **Key** — a service code (used primarily by developers);
* **Brand name**;
* **Type** — a configurable property with the default value "Default";
* **Parameters** — a free-form text field;
* **SEO code** — a short brand name for search engine optimization;
* **Description** and other options — edited in the options panel;
* **Associated files** — brand images and files (see "[File
  management](files.md)").

The list of values for the **Type** field is extended by a developer in the "Settings Registry" (see
"[Settings Registry](registry.md)"). A brand is assigned to products in the
"[Descriptions](descriptions.md)" and "[Prices](prices.md)" sections.
